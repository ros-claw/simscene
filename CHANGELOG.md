# Changelog

## 0.2.0.dev1 — V2 development candidate

Python package `0.2.0.dev1` maps explicitly to plugin `0.2.0-dev.1`.

- Unified bounded online metadata search and reviewed source registration,
  with candidate discovery separated from enabled sources.
- Immutable asset plans, selected dependency acquisition and persistent,
  reconnectable preparation/generation jobs with explicit byte budgets.
- Actual imported rigid-body and native single-DOF mappings, measured collision
  preparation, open-container proxies and self-contained HDRI lighting.
- Prepared snapshots, content verification, dependency repair and portable
  selected-role recipes that rebuild and require a new physical verdict.
- Parameterized scene compilation, two trusted optional Sand3D templates,
  native motion/contact camera proposals and explicit invisible collision proxies.
- Wheel-based portable, Claude Code and DeepSeek layouts with parallel MCP
  registration names; the original 46 MCP interfaces remain compatible.
- An independently verified, bounded paired-efficiency protocol. Cross-task
  token/time advantages remain unproven until comparable trials establish them.

Selected models and runtime limits are described in the
[capability matrix](docs/validation/catalog-capabilities.md), not inferred from
source-library names. This entry describes the development line; publication
and actual client evidence are recorded separately in release documentation.
