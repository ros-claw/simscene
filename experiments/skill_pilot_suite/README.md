`original-design/` 逐字节保留原设计。原检查器把省略源 `collision:true` 的有效动态碰撞体拒收，也误解无关节场景中省略的空 joints 字段。`supplementary-v2/` 单独修复接口并对同一记录重判，原数值与因果干预谓词保持不变：两臂 P1 修复后的正/负工程记录通过；P2 仍未稳停、翻倒或失去承托。事后物理通过不补写预算内提交，不替换原结果。

新能力的实际调用也必须看：B 读取新增制作参考，但没有调用参数模块、专用诊断、后台等待或 replay helper。这两道小题没有充分覆盖重复几何与已有事件报告诊断的成本路径；不能把它们当作这些工具有效或无效的定论。

`historical/protocol.json` 引用的是原本机绝对路径，不是能在其他主机直接执行的配置。`../run_skill_pilot.py` 是该次冻结历史执行器：其缓存变量写成 `SIMSCENE_CACHE_DIRECTORY`，而 v43 实际读取 `SIMSCENE_CACHE`。本次没有导入/下载资产，因此无对应资产缓存请求，但不能宣称已完成该缓存隔离。请求/着色器缓存也未隔离。累计 token 监控是在响应完成后检查，不能作为严格逐请求预算闸门。
