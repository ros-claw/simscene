# 试题 P2：滚动碰撞推块

请搭建一个桌面级重力碰撞台架：橙色 driver 球沿静态 ramp 下滚，碰撞蓝色自由滑块 payload，使其在水平 deck 上滑出清楚可见的一段距离并停稳。任务研究一次接触传递与摩擦停止，不用骨牌或关节传动。

必需 ID 为 driver、payload、ramp、deck。恰好两个动态刚体 driver / payload；不能有任何 joint。payload 为最初直立、各边 0.04–0.12 m 的单个 box；ramp 是静态 box 或 compound，deck 是世界水平、向上表面明确的静态 box。不得把滑块预先放在斜面上、让它自由落下，或给它初速度。

正例：driver 自首次实测位置水平移动至少 0.20 m 且下降至少 0.06 m，并有与 ramp 及 payload 的真实接触。在 ramp 接触期间，球体相对首次实测姿态至少转动 45°；不要求无滑移标定。payload 在 driver 到达前保持平静（位置不超过 0.008 m、转角不超过 3°），经碰撞后水平离开初始位置至少 0.12 m。最后 60 步中，它水平离初始位置均至少 0.10 m，位置摆幅不超过 0.012 m、转角摆幅不超过 4°，并完整位于 deck 顶面内且有承托几何，最后这段至少一次有真实 deck 接触。payload 整程中心高度变化不超过 0.015 m，倾斜不超过 10°；目标为滑动，不是跌落或翻滚。deck 顶面几何容差为 0.012 m。触发前 payload 至少两步有真实 deck 接触，首秒接触不得深于 -0.006 m。

负对照：只给 driver 的 collision_exclusions 增加 payload（源场景原先这对必须可以碰撞），其余对象与设置不变。重新真实运行：driver 仍水平移动至少 0.20 m、下降至少 0.06 m，而且仍与 ramp 接触并达到同样的球体转动要求；driver/payload 不再发生接触，payload 全程三维位移不超过 0.008 m、转角不超过 3°。不接受删球、改斜坡或让上游也停下的负例。
