# Historical pilot results

Four independent arms completed with **0/4 on-budget protocol passes**.
There is no equivalent successful pair from which to estimate token savings.
The [machine-readable summary](REVIEW-SUMMARY.json),
[usage table](usage-summary-public.csv) and
[token plot](recorded-token-costs.svg) retain the measured costs, including
failures. Missing billing information remains unknown.

[Original scores](original-v1/) and [supplemental scores](supplementary-v2/)
are separate. Supplemental v2 corrects two scorer-interface mismatches using
the same retained observations; it does not turn a late or missing submission
into an on-budget success. Original case bytes, identity checks and verdicts
remain unchanged. No new physics run was performed by the review.

The source contracts and reusable scoring methods are published. Raw sessions,
private observations and full installed runtimes are excluded. Reproduction
boundaries are described in the [reuse guide](../PUBLICATION-GUIDE.md).
