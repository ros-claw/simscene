# 可编辑参数模块

三份 definition 可交给 `skills/build-scene/scripts/plan_mechanism.py`，生成普通 add 操作、世界坐标端口及指纹。它们不启动仿真。

`line` 的牌初始竖直，需要真实的物理触发；小型 bench 脚本另外把第一张设为 12° 初始倾斜，用重力启动。正例实际倾倒 20 张；负例移除第十张，上游九张倾倒而后十张保持安静。间距 9 厘米、牌高 14 厘米保证 18 厘米缺口无法直接跨越。原先间距 6.5 厘米、固定第十张的试验没有满足“前九张全倾倒”的预先条件，失败记录保留在本地，未放宽阈值。

`bridge` 是无锁闩的重力门板，包含被动铰链和末端承托。实际八秒台架中，门板落至距水平约 0.129°，球到达 X≈0.975 米；仅锁住铰链后，球仍滚到门前但没有经过桥。相邻桌面、球和挡板来自 bench 脚本，不由模块自动生成。它不代表已经验证“拨闩触发的任意柜门”。

`arc` 通过独立 23 张弧线的普通编辑、幂等调用、修改复原、JSON/USD 往返和无初始 OBB 重叠检查；本轮未做该弧线的动态传播试验。`origin` 位于第一张牌下方，非圆心。

`*-measured-bench.json` 记录有限配置的指标和实际 job/run ID；不是通用参数范围证书。运行步骤见[制作入口](../../docs/passive-production.md)，原始条件在每次运行前封存。改变尺寸、载荷、碰撞邻居或支撑关系应重新做正例和负对照。
