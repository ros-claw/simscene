# 仓库内容与资源分发

公开项目：[ros-claw/simscene](https://github.com/ros-claw/simscene)。

## 仓库包含什么

- SimScene 源码、MCP 接口与可复用 agent skills。
- 安装、打包及场景操作脚本。
- 用户文档、示例配方、资源引用及测试。
- 精选的实际仿真影片、预览和验证摘要。

自有代码采用 [Apache-2.0](../LICENSE)，第三方边界见 [NOTICE](../NOTICE)。
开发计划、实施复盘、内部交接与工作站运维资料不作为公开使用文档分发。

## 资产与运行环境

第三方模型、机器人几何、贴图、Isaac Sim SDK、资产缓存及完整工作站工程
不随源码分发。使用在线搜索和按需获取工具，在仿真主机上取得选中的资产，
核对依赖状态，并遵守各来源的许可。

安装与首次运行见[快速开始](快速开始.md)，客户端接入见
[插件打包与安装](packaging.md)。每个示例的 README 给出配方和资源获取步骤。

## 验证范围

公开测试和精选观测记录用于源码回归与结果说明，不能替代新机器上的实际运行。
CPU CI 不代表 GPU 物理验收；完整支持范围与实验性功能见
[validation.md](validation.md)。原始会话、账户信息和完整运行归档保留在仓库之外。
