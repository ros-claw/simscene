# 开源发布范围与复现

公开仓库：<https://github.com/ros-claw/rosclaw-simscene>。

本次公开 SimScene 自有源码、通用 skill、插件构建与安装脚本、测试、
实施方案及中文实施报告。自有代码采用 Apache-2.0，第三方边界见
[NOTICE](../NOTICE)。仓库内的视频与预览为实际仿真渲染输出。

## 获取与安装

```bash
git clone https://github.com/ros-claw/rosclaw-simscene.git
cd rosclaw-simscene
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[ik]' usd-core
simscene doctor
simscene search 'industrial conveyor'
```

运行真实仿真需要另外安装兼容的 Isaac Sim，并配置：

```bash
simscene configure --isaac-python /absolute/path/to/isaac-sim/python.sh
python -m pip install -e '.[build]'
python plugins/build.py --output /absolute/path/to/new-dist --use-installed-deps
```

构建与客户端接入见 [packaging.md](packaging.md)。搜索默认使用公共
USD Search，选中资产后才获取其内容及依赖；不要求下载完整资产库。

## 公开内容与本地归档的区别

原实施工作站保存约 13 GB 的 `evidence/` 及完整资产工程。公开 Git
历史只包含经过检查的结果摘要和 CPU 回归需要的少量 JSON 观测记录。
原始会话轨迹、缓存、安装目录、完整录像、机器人几何及材质不会随
源码上传。它们的绝对路径可能仍出现在历史报告或记录中，属于当时的
运行来源说明，不是新机器必须具备的路径。

中文报告与验证历史中部分链接指向工作站完整归档。公开仓库未包含的
原始文件不能通过这些链接下载；公开内容以
[evidence/README.md](../evidence/README.md) 为索引。摘要中的通过结果
记录了原运行结论，不能仅凭摘要在新机器上复核原运行的全部输入输出哈希。

`deliverables/triarm_sorting` 是原工作站的完整交付工程，包含第三方资产，
不随公开源码分发。公开视频见 [真实仿真演示](media/triarm-demo.mp4)，
资产应通过公开工具按各来源条款重新选择和获取。

## 验证边界

CPU CI 验证源码与协议回归，不宣称运行了 GPU 物理验收。
历史完整物理套件、独立智能体用例、原始失败和新冻结修复条件，见
[实施报告](../SIMSCENE_V1_实施报告与项目复盘_20261030.md)。
本次开源发布不将开发版标为生产稳定版，也不扩大原有物理和远程测试结论。
