## 安装与第一次尝试

基础环境要求 Python 3.10+。仿真主机另需兼容的 Isaac Sim、USD 绑定及视频工具；
GLB 解码和 Sand3D 使用独立、显式配置的可选运行时。模型在选中后才取得，
3D 资产、完整 SDK 和用户凭据不随代码或安装包分发。

```sh
git clone https://github.com/ros-claw/simscene.git
cd simscene
git checkout v0.2.0-dev.1
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e . usd-core
simscene configure --isaac-python /absolute/path/to/isaac-sim/python.sh
simscene doctor
simscene catalog search 'notebook' --source abo-glb --limit 4
```

下载页同时提供 wheel 和 Linux x86_64/Python 3.10 的三客户端 ZIP。
ZIP 含 portable、Claude Code 和 DeepSeek 布局；搬迁后须重新生成 DeepSeek
本地 overlay。安装器拒绝覆盖已有目录和 skill，并支持独立 MCP 名称并排安装。
完整步骤见[打包与连接](../packaging.md)、[物理准备](../asset-catalog.md)及
[生成后端](../asset-generation.md)。现有 v43 安装可保留作为回退入口。

配置完成后，可对智能体说：

> 在线寻找一个小商品，检查来源、尺寸、许可和物理缺口，准备成刚体，
> 先做一个落到支撑面并稳定的短实验；检查实际接触和状态后再扩成四个实例，
> 输出可编辑配方和看得清动作的原生视频。

[重力分流台](../../examples/catalog_gravity_cell/README.md)提供两个来源的完整起点。
[机械展厅](../../examples/kinetic_asset_gallery/README.md)包含导入刚体、原生铰链、
生成滑道、开口接收器、光照、参数改稿与停止对照。取得必要资产后，重建新目录、
重新绑定准备产物并运行新的验收；旧结论不会自动成为新场景的通过证明。

## 已验证的交付

- 本机 CPU 回归：1,115 passed、5 conditional skips、1,311 subtests；
  Python 3.10/3.12 GitHub CI 通过。
- 两种构建路径及搬迁后的 ZIP 均通过独立环境包装／客户端检查。
  46 个旧 MCP 输入 schema 与 annotations 保持一致，新增六个工具。
- 最终分发包通过两次真实 Codex 任务：原生视频／物理，以及真实 GLB 准备／物理。
  [资格记录](../../examples/catalog_benchmark/results/release-qualification.json)保留用量与检查结果。
- 实际目标环境：Isaac Sim `6.2.0-rc.14+release.52805.02189a84.gl`、
  Omni Physics 110.4.4、OpenUSD 0.25.11、RTX A6000。
  请求 CPU 物理，加载设置读回 GPU dynamics disabled、MBP、60 Hz；
  这不是独立的执行设备遥测。
- 同步修复后的 3,600 步展厅、同条件缺中牌对照及短改稿捕获通过。
  新影片为 66 秒、原生 1080p30 来源，明确标注 0.5 倍回放、删去间隔和独立改稿。
  连续源片作为独立下载提供，所需模型通过配方按需取得。

本版修复了非空 RGB 缓冲可能落后物理帧的问题。暂停物理、刷新渲染后再批量取帧，
保留步数和时间不变检查；三次单相机与一次双相机台架通过原有像素和物理判据。
旧记录、失败和事后审计均保留原身份，没有用修复后结果替换原结论。

## 范围与实际收益

这是预览版。原生关节准备限于规范米制／Z-up 的两部件单自由度图，实际导入
SDK 样例验证了铰链；更复杂关节图和 Newton 未验证。生成后端只执行已审核模板。
Claude／DeepSeek 验证到加载和 ListTools，未声称认证模型端到端通过；
跨机器部署也需在目标环境验证。更多限制见[能力矩阵](../validation/catalog-capabilities.md)。

原候选 `599a90e` 的六任务、每版每题三次实验共 36 会话，新增能力通过 8/9；
四对严格通过的普通任务 token 比例中位数为 1.1201，未达到节省目标。
后续修复及最终包资格检查是独立证据，不构成新的跨任务收益结论。
[逐次结果与限制](../validation/catalog-efficiency.md)包含全部失败成本、缺失测量和审计说明。

SimScene 已完成从在线资产组合、物理交互验证到多机位影片交付的阶段目标，
并形成可复用制作工具；跨任务的 token 优势仍待后续真实使用验证。
