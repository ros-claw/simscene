# SimScene 快速开始

SimScene 将在线资产发现、可编辑 USD 场景、Isaac Sim 运行和影片制作接入智能体。
先在仿真主机上完成安装，再按需选择资产；不需要预下载完整资产库。

## 安装

需要 Python 3.10 或以上版本。真实仿真需要兼容的 NVIDIA Isaac Sim 和 GPU；
录像与剪辑需要 FFmpeg，具体要求见[视频接口](视频交付.md)。

```bash
git clone https://github.com/ros-claw/simscene.git
cd simscene
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e . usd-core
simscene configure --isaac-python /absolute/path/to/isaac-sim/python.sh
simscene doctor
```

机器人 IK 的附加依赖可通过 `python -m pip install -e '.[ik]'` 安装。
路径应填写当前仿真主机的实际位置。

## 在线选材

```bash
simscene search 'industrial conveyor'
simscene inspect 'ASSET_URL_FROM_SEARCH'
simscene acquire 'ASSET_URL_FROM_SEARCH'
```

默认连接 NVIDIA 公共 USD Search。搜索阶段获取候选、元数据和预览，选中后
才获取所用资产及依赖。检查获取结果的依赖状态与上游许可；`root` 是仿真端
资产路径。`USD_SEARCH_API_URL` 可替换服务地址，`SIMSCENE_CACHE` 可设置缓存目录。

## 接入智能体

在安装好的虚拟环境中运行 `simscene mcp`，或按
[插件安装说明](packaging.md)配置客户端的 stdio MCP 服务。
[build-scene](../skills/build-scene/SKILL.md) 引导选材、测量、组合、运行和观察；
[deliver-scene-video](../skills/deliver-scene-video/SKILL.md) 引导镜头与视频交付。

可以直接提出开放场景目标，例如：“搭建一个带传送带和收集箱的小工坊，
在线寻找合适资产，运行后检查交接，再调整镜头使动作清楚可见。”

复现现有作品时使用示例配方，避免从文字重新搭建：
[连锁工坊](../examples/three_level_chain/README.md)、
[精密分拣](../examples/precision_sorting_corner/README.md)、
[维修工作台](../examples/maintenance_workbench/README.md)。
先获取资源锁中的所选资产，再导入普通场景操作，并使用示例的 case 验证新运行。

## 远程仿真

在远程 GPU 主机启动服务，在客户端建立 SSH 隧道：

```bash
# GPU 主机
simscene mcp --transport streamable-http --port 8765

# 客户端，另开终端
ssh -L 8765:127.0.0.1:8765 USER@SIMULATION_HOST
```

客户端连接 `http://127.0.0.1:8765/mcp`。服务绑定回环地址，借助 SSH 保护访问。
资产、USD、缓存和运行记录留在仿真端，客户端获取图像、状态与视频数据。
已验证本机 SSH 隧道；跨机器环境仍需按实际网络和客户端验证。

## 验证与使用范围

场景规划、worker 正常退出和物理任务成功需要分别判断。检查实际观测、接触、
目标状态和必要的负对照，完整测试范围见 [validation.md](validation.md)。
自有代码及第三方资源分发范围见[开源发布说明](开源发布说明.md)。
