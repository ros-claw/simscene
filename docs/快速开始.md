# SimScene 快速开始

SimScene 为智能体提供在线资产检索、可编辑 USD 场景、Isaac Sim 运行和原生视频交付工具。
可以先查看资源与搜索元数据，再配置仿真主机；不需要预下载完整资产库。

## 从下载包完成首次交付

在 [v0.2.0-dev.2 预览版](https://github.com/ros-claw/simscene/releases/tag/v0.2.0-dev.2)下载 Linux x86_64／Python 3.10 安装包，
按[单物体首次交付](../examples/first_delivery/README.md)校验、解包和安装。
这个例子使用固定的 GSO 扫描物体与项目自建台面，提供按需获取、跌落和稳定检查、
4 秒原生视频及来源映射。

本页命令固定使用 **v0.2.0-dev.2**。来源和能力范围见
[注册表生成的资源表](../README.md#supported-asset-sources)。
来源可检索、模型能准备、物理实验通过各有对应的证据。

## 1. 安装基础包，先搜索元数据

需要 Python 3.10 或以上版本及网络。下面的目录查询不会启动 Isaac Sim，也不要求先安装 GLB 解码器。

```bash
git clone --branch v0.2.0-dev.2 https://github.com/ros-claw/simscene.git
cd simscene
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .

simscene catalog sources
simscene catalog search 'notebook' --source abo-glb --limit 4
simscene recipe list
```

首次查询可能读取有限大小的固定版本元数据索引；选中并准备对象后才获取模型与依赖。
预览图是独立操作。默认来源为 NVIDIA USD Search、ABO GLB 和 GSO GLB；
USDCraft、Poly Haven 等来源需要显式选择，例如：

```bash
simscene catalog search 'cabinet' --source usdcraft --limit 4
```

Hugging Face 仓库发现返回候选资源，不会自动把新仓库加入受支持来源，也不代表其中所有模型可直接仿真。

## 2. 配置仿真和准备环境

| 操作 | 额外环境要求 |
|---|---|
| 本地 USD 检查与场景导出 | SimScene Python 环境中的兼容 USD bindings |
| 真实物理与原生渲染 | 兼容的 NVIDIA Isaac Sim 和 GPU 主机 |
| 已验证的 ABO/GSO GLB 准备 | Isaac 资产转换器、规定版本的 Node.js/npm 与解码器、成功的 preparation probe |
| 录像与剪辑 | 带 H.264 编码及 `zscale` 支持的 FFmpeg/ffprobe，见[视频接口](视频交付.md) |

```bash
python -m pip install usd-core
simscene configure --isaac-python /absolute/path/to/isaac-sim/python.sh
simscene doctor
```

路径填写当前仿真主机的实际位置。`doctor` 检查配置，不启动仿真，也不能代替转换环境验证。
公开记录的 catalog/preparation 环境是 Isaac Sim **6.2.0-rc.14**、OpenUSD **0.25.11**；
其他版本需要单独核对兼容性。

准备 GLB 之前，按照[资产准备说明](asset-catalog.md#configure-the-preparation-runtime-explicitly)
配置 Node.js **22.23.2**、npm 和锁定解码器，再运行 `simscene asset probe`。
该 probe 会启动 SDK 应用、记录转换器能力，但不推进物理步。
`asset setup-decoder` 不负责安装 Node 本身。

机器人 IK 的附加依赖可通过 `python -m pip install -e '.[ik]'` 安装；普通元数据搜索不需要它。
预构建客户端包为 Linux x86_64/Python 3.10，对应 wheel 和迁移方法见[插件安装说明](packaging.md)。

## 3. 进一步复现跨目录示例

[跨目录重力单元](../examples/catalog_gravity_cell/README.md)包含固定 ABO 笔记本道具的
单物体检查和四实例场景。它保存资产身份、准备参数和物理 case，适合先检查跌落、接触与稳定。

这个示例同时使用 NVIDIA 工作台，工作台走原有获取路径，其个体许可仍未明确，碰撞支撑使用显式代理。
请先阅读示例说明；不要把它当成任意 ABO/GSO 模型的一键仿真入口。默认检查也不等于已经录制正式影片。

需要复现其他作品时，使用已有配方：
[连锁工坊](../examples/three_level_chain/README.md)、
[多来源动态展厅](../examples/kinetic_asset_gallery/README.md)、
[维修工作台](../examples/maintenance_workbench/README.md)。
[精密分拣配方](../examples/precision_sorting_corner/README.md)是已有兼容三臂场景的增量布景，
需要原机器人、控制器、工件和 case，不能从空场景独立重建完整三臂系统。

先获取资源锁中的所选资产，再应用场景操作，并使用对应 case 验证新运行；不沿用旧运行的物理通过结论。

## 4. 接入智能体

在安装好的虚拟环境中运行 `simscene mcp`，或按[插件安装说明](packaging.md)
配置客户端的 stdio MCP 服务。注册 MCP 和安装技能是两个步骤；使用匹配版本的：

- [build-scene](../skills/build-scene/SKILL.md)：选材、准备、测量、组合、运行和观察。
- [deliver-scene-video](../skills/deliver-scene-video/SKILL.md)：相机、原生画面审阅与视频交付。

Isaac 路径、GLB 解码器和缓存配置应在实际启动 MCP 的环境中可见，另一个终端里的环境变量不一定会被客户端继承。
安装包和客户端的验证范围见[客户端表](../README.md#connect-your-agent)；
Claude/DeepSeek 的加载检查不等于真实模型已经完成端到端场景任务。

安装 dev2 后，可用这条提示开始首次交付。

> 运行 `first_delivery` 示例，让锁定的 GSO 扫描物体落到自建台面。检查接触与稳定结果，
> 导出原生短视频并审阅动作，交付可编辑场景、验证结果和视频来源映射。

## 原有 NVIDIA USD 选材入口

已有原生 USD 工作流可以继续使用：

```bash
simscene search 'industrial conveyor'
simscene inspect 'ASSET_URL_FROM_SEARCH'
simscene acquire 'ASSET_URL_FROM_SEARCH'
```

默认连接 NVIDIA 公共 USD Search。这个旧 `search` 入口默认请求内联预览；
需要只查元数据时使用前面的 `catalog search`。选中后获取所用资产及依赖，
并检查依赖状态与上游许可。`root` 是仿真端资产路径。
`USD_SEARCH_API_URL` 可替换兼容服务地址，`SIMSCENE_CACHE` 可设置缓存目录。

## 远程仿真

在远程 GPU 主机启动服务，在客户端建立 SSH 隧道：

```bash
# GPU 主机
simscene mcp --transport streamable-http --port 8765

# 客户端，另开终端
ssh -L 8765:127.0.0.1:8765 USER@SIMULATION_HOST
```

客户端连接 `http://127.0.0.1:8765/mcp`。服务绑定回环地址，借助 SSH 保护访问。
资产、USD、缓存和运行记录留在仿真端，客户端获取图像、状态与视频数据。
已验证本机 SSH 隧道；跨机器环境仍需按实际网络和客户端验证。

[资产能力记录](validation/catalog-capabilities.md)。
自有代码及第三方资源分发范围见[开源发布说明](开源发布说明.md)。
